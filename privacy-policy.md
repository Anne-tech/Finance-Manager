# Política de Privacidade - Finance Manager

**Última atualização:** 10 de dezembro de 2025

## 1. Introdução

Esta Política de Privacidade descreve como o aplicativo Finance Manager ("nós", "nosso" ou "aplicativo") coleta, usa, armazena e protege suas informações. Ao utilizar o Finance Manager, você concorda com os termos desta política.

O Finance Manager é um aplicativo de gestão financeira pessoal desenvolvido para ajudar você a controlar suas receitas e despesas de forma simples e segura.

## 2. Informações que Coletamos

### 2.1 Dados Financeiros
O aplicativo permite que você registre e gerencie:
- Transações financeiras (descrição, valor, tipo e data)
- Categorias personalizadas de receitas e despesas
- Relatórios financeiros mensais

### 2.2 Dados que NÃO coletamos
**Importante:** O Finance Manager NÃO coleta, transmite ou compartilha nenhuma informação pessoal ou financeira com terceiros. Não temos acesso aos seus dados.

Especificamente, NÃO coletamos:
- Informações pessoais identificáveis (nome, e-mail, telefone, endereço)
- Dados bancários ou de cartões de crédito
- Localização geográfica
- Cookies ou identificadores de dispositivo
- Informações de contatos
- Fotos, vídeos ou outros arquivos de mídia

## 3. Como Usamos suas Informações

Todos os dados que você insere no aplicativo são utilizados exclusivamente para:
- Exibir suas transações financeiras
- Gerar relatórios de entradas e saídas
- Calcular saldos e totais
- Permitir a gestão e organização das suas finanças pessoais

**Todos os dados permanecem armazenados localmente no seu dispositivo.**

## 4. Armazenamento de Dados

### 4.1 Armazenamento Local
Todas as informações que você registra no Finance Manager são armazenadas **exclusivamente no seu dispositivo**, em um banco de dados SQLite local. Nenhum dado é enviado para servidores externos ou para a nuvem.

### 4.2 Segurança dos Dados
- Os dados são armazenados no armazenamento interno do aplicativo, protegido pelo sistema de segurança do Android
- Nenhuma transmissão de dados para servidores externos
- Nenhuma sincronização automática ou backup em nuvem
- Os dados são acessíveis apenas pelo próprio aplicativo

### 4.3 Backup e Exportação
O aplicativo permite que você:
- Exporte seus relatórios em formato PDF
- Os arquivos exportados ficam armazenados localmente no seu dispositivo
- Você tem controle total sobre o que fazer com os arquivos exportados

## 5. Compartilhamento de Dados

**O Finance Manager NÃO compartilha seus dados com terceiros.**

Não temos parcerias, afiliações ou relacionamentos comerciais que envolvam o compartilhamento de dados dos usuários.

## 6. Permissões do Aplicativo

O aplicativo solicita as seguintes permissões do Android:

### 6.1 Permissões Utilizadas
- **Armazenamento (READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE):** Necessária apenas para salvar relatórios em PDF no seu dispositivo quando você opta por exportar dados
- **Internet (INTERNET):** Presente no manifesto mas não utilizada para enviar dados. Pode ser utilizada por componentes do framework React Native/Expo
- **Vibração (VIBRATE):** Para feedback tátil em interações do aplicativo
- **Janela de Sistema (SYSTEM_ALERT_WINDOW):** Utilizada pelo framework de desenvolvimento para exibição de modais e sobreposições

### 6.2 Uso Responsável
Todas as permissões são utilizadas exclusivamente para funcionalidades locais do aplicativo e não para coleta ou transmissão de dados.

## 7. Dados de Crianças

O Finance Manager não é direcionado a crianças menores de 13 anos. Não coletamos intencionalmente informações de crianças. Se você é responsável por uma criança que forneceu informações ao aplicativo, entre em contato conosco para que possamos tomar as medidas apropriadas.

## 8. Seus Direitos

Como todos os dados são armazenados localmente no seu dispositivo, você tem controle total sobre eles:

- **Acesso:** Você pode visualizar todos os seus dados a qualquer momento dentro do aplicativo
- **Exclusão:** Você pode excluir transações individuais ou todas as transações através do aplicativo
- **Exportação:** Você pode exportar seus dados em formato PDF
- **Remoção Completa:** Ao desinstalar o aplicativo, todos os dados locais são permanentemente removidos do seu dispositivo

## 9. Serviços de Terceiros

O Finance Manager é desenvolvido utilizando as seguintes tecnologias:
- React Native
- Expo
- SQLite

Estas tecnologias são utilizadas apenas para o funcionamento local do aplicativo e não enviam dados dos usuários para servidores externos.

## 10. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Notificaremos você sobre quaisquer alterações publicando a nova Política de Privacidade nesta página e atualizando a data de "Última atualização".

Recomendamos que você revise esta Política periodicamente para se manter informado sobre como estamos protegendo suas informações.

## 11. Segurança

A segurança dos seus dados é importante para nós. Como todos os dados são armazenados localmente no seu dispositivo:
- Utilize recursos de segurança do seu dispositivo (bloqueio de tela, PIN, biometria)
- Mantenha seu dispositivo atualizado com as últimas atualizações de segurança
- Não faça root/jailbreak do seu dispositivo, pois isso pode comprometer a segurança dos dados
